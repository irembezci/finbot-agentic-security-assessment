# Agentic AI Goal Manipulation and Tool Misuse Testing

## Overview

An independent security assessment of an agentic AI system using the OWASP FinBot CTF environment. The assessment focuses on evaluating agent goal integrity, instruction handling, tool usage and enforcement of security constraints through structured adversarial testing.

## Assessment Focus

- Agent Goal Manipulation
- Instruction Conflict and Trust Boundaries
- Agent Tool Misuse
- Tool Authorization and Validation
- Workflow Integrity
- Security Control Evaluation

## Methodology

- System reconnaissance and attack surface identification
- Threat modeling
- Baseline behavior assessment
- Adversarial testing
- Evidence collection and validation
- Risk assessment
- OWASP mapping
- Security reporting

## Frameworks

- OWASP Top 10 for Agentic Applications
- OWASP Top 10 for LLM Applications
- MITRE ATLAS (where applicable)

## Environment

OWASP FinBot CTF

## Disclaimer

Conducted within the authorized OWASP FinBot CTF environment using its simulated workflows and synthetic data.
